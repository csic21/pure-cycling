# 设计语言：两端一套

> 需求：管理平台和 Flutter App 都必须看起来是**被设计过的**，不是模板。
> 这份文档解释意图；token 在代码里（`app/lib/app/theme.dart` 和
> `admin/app/globals.css`），两边必须同步演进。

---

## 设计对象决定了语言

这是一个装在车把上的**专业码表**。它被看的场景是：正午阳光下、戴着手套、
骑手只能用余光扫一眼。管理后台是同一个产品的另一张脸：一个运营者在桌前，
要快速找到某个账号并处理它。

两个场景指向同一种气质：**仪器的气质**。精确、可读、低功耗、不装饰。
所有下面的规则都是从这个场景推导出来的，不是审美偏好。

---

## Token

| | 值 | 用途 |
|---|---|---|
| 背景 | `#000000` | **纯黑**，不是 `#111`／`#0B0B0E`。OLED 上省电，而且对比更强 |
| 分隔 | 发丝线 `rgba(255,255,255,.08 / .24)` | 面与面之间靠线和明度差，不靠卡片和阴影 |
| 文本 | `#FFF` / `#A8ADB4` / `#6B7075` | 三级足够，不再多 |
| 强调 | `#C8FF3D` | **只表示「进行中／主操作」**。它是骑手高可视外套的颜色，不是装饰色 |
| 状态 | `#FFB020` 警告 · `#FF453A` 危险 · `#30D158` 成功 | 只在真的表示状态时出现 |
| 数字 | `font-variant-numeric: tabular-nums` | 数字是读数，不是散文；等宽数字让刷新时画面不抖 |
| 字体 | 系统字体栈 | 不下载 Web 字体：离线可用，且和 App 的观感一致 |
| 圆角 | 12–14（控件）、20（上滑面板） | 统一，不按层级随手改 |

## 规则（每条都有理由）

1. **没有阴影、没有渐变、没有毛玻璃。** 光效不是信息。层级用发丝线和明度表达。
2. **没有卡片网格。** 表格就是界面：整幅行、发丝分隔、表头吸顶。把内容切成一堆
   同样的圆角卡是模板感的第一来源。
3. **强调色只有一个含义。** 出现第二次就不再是强调。它不进标题、不进图标底色、
   不做点缀。
4. **不使用这些「生成器特征」**：全大写加宽字距的小标题（eyebrow）、用 `·` 拼起来的
   元信息串、`词语 —— 片段` 式标签、链接和按钮尾巴上的 `→`、编号装饰（01/02/03，
   除非内容真的是序列）。
5. **动效只做反馈。** 按钮按下、行展开、操作完成——可以动。整页逐段淡入、
   每张卡片悬浮抬起——不做。一个页面最多一个刻意的入场。
6. **文字是设计内容。** 主动语态；按钮说清楚按下去会发生什么（「封禁」→ 刷新后
   状态变「已封禁」，不用「提交」）；空状态邀请行动而不是抒情；错误说清发生了什么、
   下一步做什么，不道歉、不含糊。错误只有两种形状，各有对应的组件：
   `ErrorNotice`（整屏，带重试）和 `ErrorBanner`（行内）；异常原文一律进诊断日志，
   不上屏 —— 这是 `FailureReporter` 在代码层保证的，不靠自觉。

## 两端怎么落地

### Flutter（`app/lib/app/theme.dart` 是唯一真相）

- 所有颜色和字号只能来自 `AppColors` / `AppText`。页面上出现 `Color(0x...)`
  就是漂移——除非是遮罩，那也应该先在主题里定义（见 `scrim`）。
- OLED 细则已在规格里：纯黑背景、Pixel Shift、静止变暗（`docs/architecture.md`）。
- 码表层级是极端的：一个巨大的数字 + 一组安静的小标签。这是产品性格，不是排版偏好。

### 管理后台（`admin/app/globals.css`）

- CSS 变量逐条抄自 `theme.dart`，文件头写明「改这里的时候要一起改」。
- 识别度来自**结构**而不是另一套配色：整幅表格、等宽 ID、右对齐的读数、
  吸顶表头。
- 全后台只有一个刻意的姿态：登录面板顶部那道 `#C8FF3D` 起跑线。
  别处保持安静。

## 怎么保证它不被改回去

- token 只有一处定义。想在页面上写死一个颜色，必须先在主题里加一个语义化名字——
  这个摩擦是有意的。
- `flutter analyze` + 292 个测试管住 App；`pnpm run typecheck && pnpm run build`
  管住后台；两者都在 CI 里。
- 设计审查的失败项很简单：出现 `#` 开头的颜色字面量（主题文件之外）、阴影、
  渐变、第二种强调色、或者上面第 4 条里的任何一种模板特征。

> 截图自检需要桌面端启用浏览器连接；当前环境里不可用，所以这套规则靠上面
> 这些静态检查守着。能在浏览器里看的时候，改完 UI 应该先看截图再提交。
